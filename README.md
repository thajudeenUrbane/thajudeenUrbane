# Hi, I'm Thajudeen

I'm a founder and builder in Kochi, Kerala. I make software for everyday problems, and I'm working on a way to explore Islamic history that shows its evidence.

## What I'm working on

**[al-Marṣad](https://github.com/thajudeenUrbane/al-marsad)** is an open knowledge observatory for the Seerah and Islamic history.

- Every claim points to its source.
- It is a draft. Almost nothing in it has been checked by a scholar yet, and the repo says so on its first page.
- Code is AGPL-3.0. Data and writing are CC BY-SA 4.0. Identifier tables are CC0.

## How I work
